# GreenRAG · 个人混合检索 RAG 学习助手

> 上传 PDF / Word / 网页 → 自动解析分块 → **混合检索**(BM25 + 向量 + RRF)→
> 大模型生成**带引用标注(文档 + 页码)**的回答。
> 界面为白绿「英伟达风」桌面应用,内置**操作说明、环境检测(含国内镜像下载)、新手引导与 RAG 学习教程** ——
> 专为大模型工程新手 / 学生设计: 不仅开箱即用,还能边用边学会 RAG 每一步在做什么。

---

## 快速开始(3 步)

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 安装 Python 3.10+ | 用**国内直链独立安装包**(不走微软商店): [华为云镜像 3.12.10](https://mirrors.huaweicloud.com/python/3.12.10/python-3.12.10-amd64.exe) · [npmmirror 镜像](https://registry.npmmirror.com/-/binary/python/3.12.10/python-3.12.10-amd64.exe) · [官网直链](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe),安装时勾选 `Add python.exe to PATH` |
| 2 | 双击 **`一键安装.bat`** | 自动寻找 Python(自动跳过微软商店占位符)、创建虚拟环境 `.venv`,并用**清华镜像**装齐全部依赖(约 5~15 分钟,失败自动切官方源) |
| 3 | 双击 **`启动GreenRAG.bat`** | 打开桌面窗口。首次按**新手引导**完成: 环境检查 → (可选)配大模型 → 上传文档 → 提问 |

> 没有 API Key 也能完整体验: 「设置 → 大模型」保持默认的 **内置演示模式**,全流程(上传→检索→引用)真实可跑。
> 想要真正的智能回答,填任一 OpenAI 兼容服务的 Key(DeepSeek / 智谱 / 通义 / SiliconFlow / Ollama 均可,界面有预设)。
> 想先试试效果? 直接把 `examples/` 文件夹里的两份示例文档(带页码的 PDF + Word FAQ)拖进知识库即可。

## 运行原理速览

```
上传 PDF/Word/网页         提问时(每次)
┌──────────────────┐      ┌─────────────────────────────┐
│ ① 解析(记录页码) │      │ ⑤ 混合检索                  │
│ ② 分块 400字+重叠│──→   │    BM25(关键词) ┐            │
│ ③ bge 嵌入成向量 │ 入库 │    向量(语义)   ┼ RRF 融合    │
│ ④ 原文+向量入库  │      │    → top_k 片段               │
└──────────────────┘      │ ⑥ 拼入提示词 + 引用规则       │
                          │ ⑦ 大模型流式回答并标注 [n]     │
                          └─────────────────────────────┘
```

- **PDF 精确到页**: 解析时逐页提取并记录页码,分块保留页码区间,回答标注「《文档》第 X 页」;
  Word/网页无真实页码概念,标注文档名。
- **本地 GGUF 支持**: 把网上下载的 Qwen 等 GGUF 模型放进 `models/gguf`,设置页选择模型并调节 **GPU 卸载层数**(自动识别 NVIDIA 显卡型号/显存;无独显自动纯 CPU),即可完全离线跑通 RAG,便于对比不同开源模型效果。
- **混合检索**: 中文 jieba 分词 + BM25 稀疏检索,叠加本地 bge 向量稠密检索,
  用 **RRF(倒数排名融合)** 合并两路名次 —— 精确与语义互补,回答「查看检索过程」面板可逐条核对。
- **引用可溯源**: 回答中的 [1][2] 角标与下方来源卡片一一对应,点击直达原文片段,可人工核对防止幻觉。
- **隐私**: 服务只监听 `127.0.0.1`,数据全部存在本机 `data/` 目录,不上传任何第三方(调用大模型 API 时仅发送检索片段与问题)。

## 常见问题速答

- **国内下载慢?** 依赖走清华镜像(`一键安装.bat`);嵌入模型自动走 `hf-mirror.com`,仍失败可复制环境检查页里的 ModelScope(魔搭)命令下载。
- **上传扫描版 PDF 失败?** 程序暂不支持 OCR,请用文字版 PDF / Word。
- **改了分块参数没生效?** 改完后到「知识库」页点 **重建全部索引**(界面会提示)。
- **回答不理想?** 打开该回答的「查看检索过程」: 若余弦都很低 → 知识库缺内容或换问法;若命中正常 → 换真实大模型或调大 top_k / 降低温度。
- **想彻底卸载?** 删除项目文件夹即可(数据都在项目内,不写注册表、不留后台进程)。
- 更多问题见应用内「学习教程 → FAQ 与术语表」。

## 进阶开发参考

- 想打包成免 Python 环境的 exe:
  `pip install pyinstaller` 后执行
  `pyinstaller -F -w --collect-all sentence_transformers app.py`(体积较大,建议随包分放 `data/models`)。 
- 更换嵌入模型: 「设置」中直接改模型名(任意 HuggingFace 中文向量模型,如 `BAAI/bge-large-zh-v1.5`),下载后重建索引。
- 接入自己的 RAG 服务: 修改 `core/llm.py` 的 OpenAI 兼容调用,或直接参考 `server.py` 中 `/api/chat` 的检索→生成编排。

## 上传到 GitHub(三步)

本项目已内置 `.gitignore`(自动排除 `data/` 运行数据、`models/` 本地模型与引擎、`.venv/` 虚拟环境),
体积很小,可直接推送:

```bash
# 1. 在 GitHub 网站新建一个空仓库(不要勾选 README/.gitignore)
# 2. 关联远程仓库(替换成你的地址)
git remote add origin https://github.com/你的用户名/GreenRAG.git
# 3. 推送
git push -u origin main
```

> 提示: 首次使用 git 需要先设置身份: `git config --global user.name "你的名字"` 与
> `git config --global user.email "你的邮箱"`。
> 若使用 GitHub Desktop / VS Code,直接「Add local repository」选中本文件夹再 Publish 即可。
