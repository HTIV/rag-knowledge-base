    知识库速览

    本页功能说明点一下展开 —— 每个按钮在做什么、对应 RAG 的哪个环节
    1. 上传文档 / 粘贴网页链接 —— RAG 的第 1 步「文档摄入」：程序解析 PDF(逐页提取文字)、Word、TXT、Markdown、HTML 与网页正文。
    2. 自动分块 —— 解析出的文字按「分块大小」切成一段段(默认 400 字),块与块间有重叠,防止答案被切断。每块会记住它来自哪篇文档、哪个页码。
    3. 向量化 —— 每块文字交给嵌入模型转成 512 维向量,连同原文一起入库。上传窗口会实时显示每个环节的进度。
    4. 提问前先看统计 —— 右上角显示文档数、分块数。分块数太少说明文档还没入库完成。
    5. 管理文档 —— 每一行可「查看分块」(检查切分效果,搜索定位关键词)、「打开原文」(系统默认软件打开备份)、「删除」(彻底移除)。
    6. 重建索引 —— 在「设置」里改过分块大小/重叠后,旧块与新参数不一致,会出现提示条,点它按新参数重新分块入库。

    💡 学习点：文档摄入(Ingestion)质量决定检索上限 —— PDF 是扫描件没有文字层时无法解析(本应用暂不支持 OCR),请使用文字版 PDF 或 Word。

    本页功能说明问答 = 检索 + 生成。回答下方的引用编号,会标出「出自哪篇文档的哪一页」
    1. 输入问题,回车提问。程序会先把问题转成向量,同时在全部文档分块里做混合检索,选出最相关的片段。
    2. 查看检索过程(回答上方按钮): 每一条命中都标注了「向量排名 / 关键词排名 / 融合分」,这是理解混合检索最好的窗口。
    3. 引用溯源: 回答中带 [1] [2] 的位置,点击下方来源卡片即可看到原文片段;PDF 会精确到页码。
    4. 仅知识库回答 开关: 开启时模型只依据你的文档作答,超出资料的内容会如实告诉你「没找到」。
    5. 换一批参数? 片段数量(top_k)、是否携带多轮对话等在「设置」页调整。

    💡 学习点: 这个页面就是 RAG 的 ② 检索(Retrieval)与 ③ 生成(Generation)。多问几轮,对比不同 top_k 下回答质量的差别。

    本页功能说明逐项列出运行 GreenRAG 所需的环境;缺失项旁边有「国内镜像下载链接」与「一键复制安装命令」
    1. 点击 重新检测 刷新全部检查项(结果只读本机,不上传任何数据)。
    2. 红色 ❌ 的项目按 「必须补齐」 处理 —— 点它右侧的按钮: 链接类会打开下载页,命令类会复制到剪贴板,粘贴到「命令提示符 / PowerShell」回车即可。
    3. 最省事方案: 直接双击项目根目录的 一键安装.bat,它会自动创建虚拟环境并用国内镜像装齐所有 Python 依赖。
    4. 绿色 ✓ 表示该项满足。黄色 ⚠️ 表示非必需(不影响使用)。
    本页功能说明所有可调参数都在这里,每个参数旁边都有说明。修改自动保存,无需点保存按钮
    1. 大模型: 选择服务商预设(DeepSeek/智谱/Ollama…),填入你的 API Key 即可。没有密钥可以先选「内置演示模式」体验全流程。
    2. 嵌入模型: 默认本地 bge-small-zh-v1.5(约 95MB,一次下载永久离线使用)。也可以用 API 模式调用服务商的 embedding 接口。

    4. 网络: HF 镜像开关默认开启(国内下载模型必需)。
    5. 每个参数改完即自动保存,右上角出现「已保存」提示。
